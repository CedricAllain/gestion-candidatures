# Gestion des candidatures

Application web locale destinée à faciliter la consultation et, à terme, le traitement des dossiers de candidature. Elle permet actuellement de parcourir les dossiers des candidats, de lire les courriels de candidature au format Outlook `.msg` et de consulter la liste de leurs pièces jointes.

Le projet a vocation à évoluer vers l’identification des documents transmis, l’extraction structurée des informations des candidats et l’aide à la vérification des dossiers. Ces fonctionnalités futures seront développées progressivement.
